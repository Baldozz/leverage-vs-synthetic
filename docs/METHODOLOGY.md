# METHODOLOGY.md

Notation: all amounts in USD (`float64`), time in years, `dt` = 1/12 (monthly), 1/52 or 1/252.
P = real-world measure (path simulation, `fosim.market`); Q = risk-neutral measure (option
pricing, `fosim.pricing`). Each formula names its implementation and the test that checks it.

## 2. Market models (P) — `fosim/market/*`, tests `test_07_14_market.py`, `test_market_bootstrap_stress.py`
**Random streams** (`generator.spawn_streams`): `SeedSequence(seed).spawn(10)` in the fixed order equity, held, illiquids, iv, rates, jump_clock, jump_size, iv_jump, bootstrap, counterparty; all drawn every run (test 14). Correlated shocks Z_corr = Z_indep · Lᵀ, L = Cholesky of the validated matrix over [indices…, illiquids…, IV, RATES] (`correlation.validate_correlation`; Higham 2002 repair with warning, test 9).

**Equity index i** (`equity.simulate_indices`):
- GBM (exact): ln S_{t+dt} = ln S_t + (m − q_c^{px} − σ²/2) dt + σ√dt Z (test 7). q_c^{px} = q_c (price return), 0 (total return), q_c − ln(1 + q(1 − WHT)) (net total return).
- Merton: + Σ_{N_t} J, N ~ Poisson(λ dt) common across indices, J ~ N(μ_J, σ_J²) index-specific; compensator −λκ dt, κ = e^{μ_J + σ_J²/2} − 1 (test 8).
- Coupled stochastic vol: σ_t = IV_s,t (1 − vrp) at the start of the step.
- Held portfolio: Δln H = Σβ_i Δln S_i + (α − σ_ε²/2)dt + σ_ε√dt ε (`simulate_held_portfolio`, test 38).
- Stationary block bootstrap (Politis–Romano, `bootstrap.py`): geometric block lengths with mean L, rows resampled jointly, optional re-centring of index log-means to (m − q_c^{px} − σ²/2)dt.

**Implied vol** (`implied_vol.simulate_iv_short`): x = ln IV_s, x_{t+dt} = x_t e^{−κdt} + ln θ(1 − e^{−κdt}) + η√((1 − e^{−2κdt})/(2κ)) Z_IV + j_IV N_t, clipped to [floor, cap]; stationary mean ln θ, variance η²/(2κ) (test 11).

**Rates** (`rates.py`): flat (constant or user term structure); Vasicek exact step r_{t+dt} = r_t e^{−a dt} + b(1 − e^{−a dt}) + σ_r √((1 − e^{−2a dt})/(2a)) Z_r, P(τ) = exp(A − B r), B = (1 − e^{−aτ})/a, A = (B − τ)(a²b − σ_r²/2)/a² − σ_r²B²/(4a), y = −ln P/τ (+ term premium) (test 10); curve: par bootstrap (annual coupons) → log DF, linear in log DF, shifts parallel / steepener / flattener / buckets (test 34). Derived: loan base = r_t, cash = r_t − spread_cash, option rate = y_t(τ) + funding spread.

**Illiquids** (`illiquids.py`): ln(1+G) = (m − σ²/2)dt + σ√dt Z + β_J J − λ(e^{β_J μ_J + β_J²σ_J²/2} − 1)dt; Geltner on the unit growth index I_true = Π(1+G): at report dates r_true = I_true/I_true,last − 1, r_obs = (1−φ) r_true + φ r_obs,prev, I_obs ← I_obs(1 + r_obs); NAV_rep = NAV_true · I_obs,last / I_true (test 12). Takahashi–Alexander: C = RC_step U (× crisis), U ← U − C, RD = min((age/L)^B, 1) per year → per step (× crisis), D = RD · NAV(1+G), NAV ← NAV(1+G) + C − D (test 13).

**Stress** (`stress.py`): stylised shapes (see ASSUMPTIONS 27) and historical replay from user CSVs; both return single-path `MarketPaths`.

## 3. Option pricing (Q) — `fosim/pricing/*`, tests `test_01_06_pricing.py`, `test_24_27_greeks_strikes.py`, `test_32_40_vol_surface.py`
- BSM: C = S e^{−qT} N(d₁) − K e^{−rT} N(d₂), d₁ = [ln(S/K) + (r − q + σ²/2)T]/(σ√T), d₂ = d₁ − σ√T; limits T→0 (intrinsic), σ→0 (discounted forward intrinsic) (`black_scholes.bsm_price`, tests 1, 2, 5; MC test 6; parity test 3).
- Greeks (`bsm_greeks`, test 4 FD, test 24 values): Δ = e^{−qT}N(d₁); Γ = e^{−qT}φ(d₁)/(Sσ√T); vega = S e^{−qT}φ(d₁)√T; θ = −S e^{−qT}φ(d₁)σ/(2√T) + qS e^{−qT}N(d₁) − rK e^{−rT}N(d₂); ρ = K T e^{−rT} N(d₂); ∂C/∂q = −S T e^{−qT} N(d₁); Ω = ΔS/C. Reporting conventions (`reporting_greeks`): dollar delta Δ n S; dollar gamma Γ n S² × 0.01; vega per point × 0.01; theta per year and /365; rho per bp × 1e-4 and per 100 bp × 0.01; ∂C/∂q per 100 bp.
- Smile delta (`greeks.smile_delta`, test 30): Δ_smile = Δ + vega·(−ψ/S) under sticky moneyness; = Δ under sticky strike.
- Implied vol (`implied_vol.implied_vol`, test 31): brentq on σ ∈ [1e-8, 10] after checking max(S e^{−qT} − K e^{−rT}, 0) ≤ C < S e^{−qT}.
- Surface (`vol_surface.ParametricSurface`): IV_ATM(T,t) = θ_T (IV_s,t/θ_s)^{β(T)} (θ_T, β(T) linear in T); σ(K,T,t) = max(IV_ATM + ψ(T)·k, floor), ψ(T) = ψ_1y/√T, k = ln(K/F) with F = S e^{(r−q)T} (sticky moneyness) or k frozen at purchase (sticky strike).
- Grid surface (`GridSurface`): w = σ²T linear in T, PCHIP across log-moneyness; calendar check w non-decreasing in T; butterfly check ∂²c/∂K² ≥ 0 on a fine grid of normalised call prices (test 32).
- Price sources (`VolSource.vol`, test 40): scenario override → dealer quote at (tenor, strike) → surface file → parametric (level-calibrated by quotes); returns the label recorded per tranche. Bid/ask: σ ± ½ spread (new vs unwind), × stress multiplier when IV_s > threshold.
- Strikes (`option_ladder.quote_new_tranche`, tests 26, 27): ATM spot K = S; ATM forward K = F; pct modes; delta target by vectorised bisection with σ(K) re-evaluated (scalar brentq version `solve_delta_target_strike`).

## 4. Instruments — `fosim/instruments/*`, tests `test_18_20_35_loan_margin.py`, `test_23_ladder_schedule.py`
- Loan rate: max(r_t, floor) + spread(tier) fixed at reset dates; interest L·rate·days/360 on the start-of-step balance, paid or capitalised (test 20); commitment fee on the undrawn limit (test 35); arrangement fee once; swap MTM L[(1 − DF(T)) − fixed Σ DF Δ].
- Lending value LV = h(state)·(ℓ_E E + ℓ_I I + ℓ_cash max(cash,0)), h = min multiplier of breached stress rules; u = L/LV; d* = 1 − (L − ℓ_I I)/(ℓ_E E₀) (test 18); cure sale x = (L − u* LV)/((1 − s) − u* ℓ) (test 19); cash cure R = (L − u* LV)/(1 − u* ℓ_cash).
- Ladder schedule (`LadderSchedule`, test 23): rolling ladder — slot j bought at months j + nH, sold at bid before each repurchase, expiry = purchase + 12 T₀; hold-to-expiry — repurchased at expiry; bullet — bought at 0, rolled every (T₀ − R) months.
- Book marks (`mark_book`): per slot σ from the source at the current (or frozen) k, r = y_t(T_res) + funding spread, q = pricing curve at T_res; value at mid and bid; aggregated Greeks in reporting units.

## 8. Call-vs-cash backtest — `fosim/analytics/call_vs_cash.py`, test `test_call_vs_cash.py`
Daily data `data/market_data_daily.csv`. For every trading day t₀ in [start, end] with maturity T = trading day nearest to the calendar date t₀ + 12·tenor months (≤ last date):
- premium fraction c(t₀) = BSM_call(S = K = 100, r = q = y_n(t₀), σ = IV_n(t₀), τ = tenor) / 100, where y_n and IV_n are the `ust_{n}y` / `iv_{n}y` columns of the tenor when present, else the 5-year columns (reported via `BacktestInfo.fallback`); q = r because SPXFP is an excess-return index (forward = spot); or c fixed by the user;
- notional N = P / c(t₀) for the USD premium P; call P&L = N · max(SPXFP_T / SPXFP_{t₀} − 1, 0) − P (floored at −P by construction);
- cash P&L = P · (I_T / I_{t₀} − 1), I = SPXFP, or I = SPX_px · exp(Σ ln(1 + d_i/100)·(1 − WHT)·Δt_i) with d = trailing 12-month S&P dividend yield (percent) and Δt in ACT/365 years — dividends reinvested continuously net of withholding;
- returns on the USD committed = P&L / P; annualised mean = (1 + mean)^{1/tenor} − 1.
No bid/ask, no early unwind, no discounting of the premium to maturity (both legs commit the same USD at t₀ and are read at T).

## 9. Keep the loan vs. rotate into calls — `fosim/analytics/leverage_stress.py`, test `test_leverage_stress.py`
One historical path from t₀ (any trading day) to the last data day; daily file, all amounts USD. TR(t) = SPX with dividends reinvested continuously net of withholding (§8), rebased to 1 at t₀; S(t) = SPXFP.
- **A, keep the loan**: E_A(t) = E₀ · TR(t); loan L(t+1) = L(t) · (1 + (base_t + spread) · Δt), simple interest ACT/360 capitalised daily (base = 3m LIBOR to 2018, Term SOFR after); lending value ℓ_E · E_A; LTV_A = L / (ℓ_E · E_A); room before a margin call = m · ℓ_E · E_A − L with m the call level (`margin_call`, 0.90 default: the bank calls when the loan exceeds m of the lending value; negative = margin call, |·| the cure amount); the further SPX fall to the call is 1 − LTV/m. NAV_A = E_A − L.
- **B, rotate into calls**, in n weekly steps (default 52; 1 = one shot), step w on the trading day nearest t₀ + 7w days: with c_w = BSM_call(S = K = 100, r = q = y_n, σ = IV_n, τ = tenor)/100 and δ_w = ∂C/∂S of the same call (the model delta of the ATM call, ≈ 45–50 % at 5 years), sell x_w = (L_w / remaining steps) / (1 − c_w/δ_w) of SPX, buy notional N_w = x_w / δ_w (δ_w · N_w replaces the exposure sold, so E_B + Σ δ·N stays E₀ at the end of the build), pay c_w · N_w, repay L_w / remaining steps of the loan still outstanding; the loan is zero after step n. Between steps the remaining loan accrues as in A. Calls are marked daily with BSM (q = r, remaining tenor ACT/365, vol and Treasury of the day for the tenor). **Live exposure** (path columns `exposure_A`, `exposure_B`): X_A(t) = E_A(t); X_B(t) = E_B(t) + Σ_live units_k · δ_k(t) · S(t), δ_k(t) = ∂C/∂S of tranche k with BSM(q = r, vol and Treasury of the day, τ = calendar days to its expiry day / 365 — the marks' convention, so on the purchase day δ is a hair off the tenor's δ_w; `exposure_replaced_B` keeps the purchase-day version E_B + Σ δ_w · N_w). At expiry a tranche pays units · max(S_T − K, 0). **Replaced exposure** (`exposure_replaced_B`): R_B(t) = E_B(t) + Σ_live δ_buy,k · N_k · TR(t) / TR(t_buy,k) — what the holdings were bought to carry, each call's slot grown with the total-return index like the SPX it replaced (a call bought at a band check carries δ · N from its purchase day; partial sales reduce N_k). **Target roll** (`roll="target"`, default): with the expiring tranches settled, gap = X_A − R_B(surviving); gap ≤ 0 → nothing bought, `Roll.skipped`; else with c = c_t and δ = δ_t(τ to the new expiry day), N = gap / δ if c · gap / δ ≤ cash (payoff + T-bills), otherwise N = (gap − cash) / (δ − c) and s = c · N − cash of SPX sold (from δ · N − s = gap and c · N = cash + s), so R_B = X_A after the roll (each replacement restores its own slot, x_w · TR(t)/TR(t_w) when nothing else changed; X_B = X_A too when no tranche survives); if s > E_B, s = E_B, N = (cash + s) / c, `Roll.cut`. M tranches expiring the same day: one gap, N / M each. **Delta / units rolls** (`roll="delta"` / `"units"`): an in-the-money call is replaced by a new ATM call carrying the same dollar delta (the expiring call is intrinsic, delta 1, exposure units · S_T, notional units · S_T / δ_new — about twice the units) or on the same index units (notional = units · S_T); a worthless call is replaced on the same index units (`replace_worthless=True`, default) or lapses (`False`: nothing bought, no SPX sold; under the target rule an all-worthless expiry lapses too). Under these two rules a replacement is paid from the payoff, then from the T-bills, then by selling SPX **delta-for-delta**: the share f of the premium the SPX pays for sells f · δ_new · N of SPX, the premium is paid out of it and the excess goes to T-bills, so the sale leaves the exposure unchanged (Δcash = payoff − premium + SPX sold); when not even all the SPX can fund the tranche, N is cut to cash / c + SPX / δ_new (all the SPX sold) and the roll is flagged `cut` (`Roll.cut`, `B: cut rolls`, CSV "replacements cut for lack of SPX"); a payoff left over after the premium is kept in T-bills (simple ACT/360), reinvested in SPX or in more calls (`surplus`; not used under the target rule). **Band rebalance** (target rule only; `rebalance` monthly by default, or quarterly, or none; `band` = 0.10): on the last trading day of each period after the build, if X_B > (1 + band) · X_A the excess X_B − (1 + band) · X_A is sold from the calls, most in the money first (highest S/K, then the earliest expiry), u = min(units_k, excess / (δ_k · S)) units of each at the sale price BSM(σ − h, τ_k) per unit (h = `unwind_haircut`, 0.01 default), proceeds to T-bills, unwind cost u · (mark − sale) booked; if X_B < (1 − band) · X_A the shortfall (1 − band) · X_A − X_B is bought from the T-bills: ATM calls of the tenor (a new tranche with its own expiry): `below="calls_spx"` (default) buys N₁ = min(shortfall / δ_t, cash / c_t) from the T-bills and, for the rest G, sells s = G / (δ_t/c_t − 1) of SPX (capped at E_B, then `Trade.partial`) for s / c_t more notional, so δ · N − s = shortfall and the exposure lands on the edge; `below="calls"` stops at the T-bills (partial when they fall short); `below="spx"` buys SPX for min(shortfall, cash). Trade log `StressInfo.trades` (`Trade`: date, event, exposure before / after, target, band edge, USD traded, notional, SPX, price per unit of notional, delta, strike, expiry, partial, cut), `trades_table` for export. Dry powder (capacity to borrow before the call) = m · (ℓ_E · E_B + ℓ_C · calls + ℓ_T · cash) − loan_B, with ℓ_T the lending value of the T-bills the payoffs are kept in (90 % default, `ltv_cash`) and m the call level; `cap_B` is the lending value itself. NAV_B = E_B + calls + cash − loan_B.
- **Accounting identity**, asserted every day for both: ΔNAV_A = ΔE_A − interest; ΔNAV_B = ΔE_B (on the units held) + Δcalls (marks before any early sale + payoffs − yesterday's book) + cash interest − loan interest − unwind cost (`unwind_cost_B`: an early sale moves u · mark out of the calls and u · sale into the T-bills), to 1e-6 USD per 1 bn of NAV (`AccountingIdentityError` otherwise). The two portfolios have the same NAV on t₀ by construction (each step is NAV-neutral).
- Page 1's grid runs from the first data day to a week before the end day (today or a bottom alike; `_iter_starts` skips only starts less than 7 days before `until`). A start whose weekly build is not complete by the end day takes the steps that fall before it (`simulate` drops the build days on or after the last day of the path, so the loan is partly repaid and only those tranches are held: "still rotating", counted in the header from `end: loan B > 0`); held to today, the starts after last day − tenor − 7·(n − 1) days have tranches that never reached expiry and are flagged (count in the header).
- `rolling_starts`: the same setup put on at every start of a grid and run to a fixed date or for a horizon; one row per start (returns, least room / least capacity and their dates, interest, premiums, payoffs, end balance sheet, number of calls that expired worthless, the first day after the build with no call left = when the option part was lost, the call notional at the end). Annualised return = (NAV_end / NAV_start)^{1/years} − 1 with years = calendar days / 365.25.
- `rolling_paths`: the same rows plus, for chosen path columns (room before a margin call of A, dry powder of B, NAVs), a wide table per column — value on the last trading day of each month (and the last day), one column per start, NaN before the start. The dry-powder page reads the 5th / 50th / 95th percentile across the starts alive on each date. On the end day page 1 gives the annualised return (NAV_end / NAV₀)^{1/years} − 1 over the starts (lowest, percentiles, highest of each portfolio, Δ per row, count of starts where B > A). The corrections table gives, per correction, the lowest NAV of each portfolio on the bottom day across the starts running that day (checked this session: on every correction both portfolios reach their low of the episode on the SPX bottom day itself). The per-bottom tables show the start with the lowest NAV that day in either portfolio, read on both strategies (Δ like for like on every row), plus the count of starts alive that day where dry powder B > A (`test_app.py` recomputes both from `rolling_paths`). The block gives the balance sheet on the bottom day — NAV, SPX, T-bills (the payoffs kept in cash), calls, loan, lending value (ℓ_E · SPX + ℓ_C · calls + ℓ_T · T-bills), dry powder = lending value − loan — and the interest cumulated on each loan from the running totals `interest_cum_A`, `interest_cum_B` of `simulate` (B's accrues only while the build is repaying it, and is paid by the SPX sold, so Σ SPX sold over the build = L₀ + interest_B + premiums; `test_cumulative_cost_columns_match_the_summary`, which also checks the other running totals `premiums_cum_B`, `payoffs_cum_B`, `div_cum_A`, `div_cum_B` — the dividends per day are units held over the day × (TR(t) − TR(t−1) · px(t)/px(t−1)), reinvested, reported in the CSV but not on the page: a footnote states the reinvestment). The calls row counts the tranches alive (`n_calls`) out of those bought to that day (`n_bought`: build steps done plus replacements at expiry), and says how many of the weekly steps were done when the bottom came before the rotation was complete.
Tests: closed-form loan accrual; the one-shot rotation's x, N, NAV-neutrality and delta exposure against `bsm_price`/`bsm_greeks`; the margin-call day against the closed form 1 − L/(ℓ E₀); four-step ladder (equal steps, loan quarters, four rolls a week apart); roll cash flows rising and falling, the three surplus policies; identity columns; rolling-start rows against the single path; real data 1997 → today (52 steps, loan gone in 1998, no margin call, 2009 the deepest fall). ## 10. Five scenarios (separate, simplified exercise) — `fosim/analytics/five_scenarios.py`, test `test_five_scenarios.py`
Independent of §9: none of its rules (delta-sized rotation, roll to Keep's exposure, band) apply here, and nothing in §9 depends on this section; only the data, the pricer (§3) and the total-return convention (§8) are shared. One historical path from t₀ to the last data day for each of the investor's five ways to hold a capital C (page "Five scenarios"); daily file, USD; TR(t) = SPX with dividends reinvested continuously net of withholding (§8) rebased to 1 at t₀; S(t) = SPXFP. A loan share ℓ (0.25), the call sleeve sized by **premium** κ (0.25 of the capital, `sizing="premium"`, default — the note's 162.5 m) or by **exposure** X (0.86 of the capital in SPX-equivalent, `sizing="exposure"`, option), a flat loan rate ρ (0.055) or the 3m base rate + spread, a premium fraction c (0.145 of notional) or the market's, a tax rate τ (0.24), the tenor n years (5), a build of N steps (52) a week (7 calendar days) or a month apart (`build_steps`, `build_unit`).
- **The build**: step w (w = 0 … N − 1) falls on the trading day nearest t₀ + 7w days (or + w months); steps on or after the end day are not taken (`ScenarioInfo.n_tranches` counts the ones taken, `build_end` the last). One slot of premium on step day k: P_k = (X·C/N) · c(k)/δ(k) under exposure sizing — δ(k) the model delta of the ATM call at the vol c implies (or the market's), so the slot carries exactly X·C/N of SPX-equivalent (delta × notional) at purchase — or P_k = κ·C/N under premium sizing. Set-up: **1** E = C. **2** E = (1 + ℓ)·C, L = ℓ·C at t₀. **3** E = C, each step sells P_k of SPX (capped at the SPX held) for the slot. **4** E = C, each step draws P_k as a loan for the slot (L = Σ P_k at the end of the build). **5** E = C, each step sells E/(N − w) of the SPX still held for calls — all of it at the last step — whatever the sizing. A tranche bought for P on day t has notional N_t = P / c(t), units N_t / S(t), strike S(t), expiry the trading day nearest t + 12n months (beyond the data: held to the end, `unexpired`). **Fixed premium** (`premium=0.145`): c(t) = c; the tranche is marked from the next day to the day before expiry with BSM(S, K, r = q = y_n(t), σ*, τ ACT/365) at σ* = the vol implied by c on its purchase day, `implied_vol(100c, 100, 100, y_n(t), y_n(t), n)`, kept constant for that tranche — the purchase is NAV-neutral and no market vol is invented. **Market premium** (`premium=None`): c(t) = BSM(100, 100, y_n, y_n, IV_n(t), n)/100 and the marks use IV_n of the day (§9's convention). N = 1 with premium sizing is the 29-Sep rule (one call on the start day, κ·C of premium).
- **Dollar delta and exposure**: `call_delta`(t) = Σ over the live tranches of units · δ_i(t) · S(t), δ_i the BSM delta at the tranche's vol and its calendar time to expiry (on the purchase day the sizing delta δ(k), so the slot's delta is X·C/N to the cent); `exposure` = E + call_delta, the SPX-equivalent of the whole portfolio (what a 1 % move in the index does to the NAV, × 100). Scenarios 1 and 2: exposure = E.
- **Loan**: L(t+1) = L(t)·(1 + ρ_t·Δt), simple interest ACT/360 capitalised daily (ρ_t = ρ, or base_t + spread); scenario 2 repays it from SPX on the trading day nearest t₀ + 12n months (`repay="tenor"`: SPX sold = min(L, E)) or never (`"never"`, NAV net of it); scenario 4 repays it slot by slot (below; `repay_calls="surplus"` or `"refill_spx"`) or never (`"reborrow"`: every replacement call on a new loan). Cash (only what a last-day expiry leaves) earns the 3m T-bill the same way.
- **Expiry** on day T of a tranche from slot i with units u, strike K, premium paid P: payoff π = u·max(S_T − K, 0); tax θ = τ·max(π − P, 0) for the scenarios in `tax_on` (3, 4 and 5 by default; 5 can be left out), no loss carry-forward, no tax on the SPX; proceeds = π − θ. Then: **3** (`rebalance="portfolio"`, default): V = E + the marks of the surviving tranches + the premiums bought earlier that day + proceeds (the NAV after tax); the slot is refilled with P′ = (X·V/N)·c(T)/δ(T) (exposure sizing) or κ·V/N (premium sizing), capped at proceeds + E; SPX bought = proceeds − P′ (sold when negative) — so a worthless slot sells SPX for its replacement, a paying one buys SPX with the rest, and with N = 1 this is exactly the 29-Sep rule (V = E + proceeds, SPX to (1 − κ)·V, calls κ·V). `"proceeds"` (premium sizing only, refused otherwise): SPX bought (1 − κ)·proceeds, calls κ·proceeds, nothing on a worthless expiry. **4** (`repay_calls`): `"surplus"` (default) — while the loan is outstanding and the tranche is one of the build's, its share L/m (m = build tranches not yet expired, this one included) is repaid from the proceeds, then from SPX sold for the shortfall (capped at E; a loan left with no SPX stays and is a margin call); the rest buys the new tranche, no new loan — so the loan is gone at the last build tranche's expiry, and a worthless build slot sells SPX and buys nothing; later cycles roll the after-tax proceeds. `"refill_spx"` — the same repayment, then the slot is refilled with P′ = slot(V) (κ·V/N or the exposure equivalent, V = NAV after tax = E + surviving marks + premiums bought earlier that day + cash − L), capped at cash + E, SPX bought = cash − P′; every cycle. `"reborrow"` — no repayment; the after-tax proceeds buy SPX; the slot is refilled with P′ = slot(V) drawn as a new loan (`Expiry.loan_drawn`); every cycle; L runs to the end. **5**: the proceeds buy the new tranche; π = 0 lets the slot lapse; the scenario is wiped out (`wiped_out_on`, NAV 0 thereafter) the day no tranche is alive and no cash is left, once the build is over. An expiry on the last day settles and keeps the cash. Every expiry is logged with its slot (`Expiry`: payoff, premium paid, tax, loan repaid, SPX traded, new premium and notional, worthless, wiped out).
- **Margin call** (2 and 4; NaN for the others): lending value ℓ_E·E + ℓ_C·calls + ℓ_T·cash, LTV = L / lending value (0 once repaid), headroom = m·lending value − L; a day with headroom < 0 is in margin call (first day, days in call, LTV that day, highest LTV in `ScenarioInfo`); flagged, no forced sale.
- **NAV** = E + calls + cash − L; **accounting identity** asserted every day for every scenario: ΔNAV = ΔE (units held over the day) + Δcalls (marks before the day's trades + payoffs − yesterday's book) + cash interest − loan interest − tax, to 1e-6 USD per 1 bn (`AccountingIdentityError`). Purchases, sales, loan draws and repayments are NAV-neutral at the mark; the tax is the only outflow.
- `default_starts`: the first data day, the dot-com peak and bottom (the first ≥ 20 % correction on the SPX price index, `corrections(on="price")`) and the GFC peak and bottom (the second correction), in date order. `summary`: one column per scenario — NAV, total and annualised return (NAV_end / NAV₀)^{1/years} − 1 with years = days / 365.25 (−100 % when wiped out), lowest NAV and its day, max drawdown, the margin call, the loan, the build (its end, the premium paid, the exposure on its last day), the expiries, premiums, payoffs, tax, interest, SPX traded at expiries, the holdings (calls alive, notional, exposure today). `paths_table`: every (start, scenario, day) for export, USD m (`call_delta`, `exposure`, `n_calls` included).
